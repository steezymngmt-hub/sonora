# SONORA

Sito statico per GitHub Pages. Le playlist vengono riprodotte tramite i player ufficiali Spotify incorporati: nessun MP3 viene scaricato o ospitato.

## Pubblicazione con GitHub Pages

1. Crea un nuovo repository GitHub, ad esempio `sonora`.
2. Carica `index.html` nella cartella principale del repository.
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona il branch `main` e la cartella `/ (root)`, poi salva.
6. Attendi la pubblicazione: GitHub mostrerà l'indirizzo pubblico del sito nella sezione Pages.

I player incorporati richiedono una connessione internet e dipendono dalle impostazioni di disponibilità e riproduzione di Spotify. I visitatori possono anche aprire direttamente ogni playlist con il pulsante “Open on Spotify”.
